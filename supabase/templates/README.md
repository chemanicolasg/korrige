# Plantillas de correo de Supabase Auth

Se pegan a mano en el panel: Authentication → Emails → Templates (pestaña «Source»). Requieren tener activado el SMTP propio (Resend) para que salgan de `no-reply@korrige.es`.

| Plantilla de Supabase | Archivo | Asunto (Subject) |
|---|---|---|
| Confirm signup | `confirmacion.html` | Confirma tu correo para entrar en Korrige |
| Magic Link | `enlace-magico.html` | Tu enlace para entrar en Korrige |
| Reset Password | `recuperar-contrasena.html` | Elige una contraseña nueva para Korrige |
| Change Email Address | `cambio-de-correo.html` | Confirma tu nuevo correo en Korrige |
